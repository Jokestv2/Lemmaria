# ACM conference (sigconf) — submission requirements / 投稿要求

## Page limit / 页数限制

9 pages excluding references (typical sigconf limit — **always check your conference's CFP**).
正文 9 页（不含参考文献；以会议 CFP 为准）。

## Anonymity / 匿名要求

Double-blind: submit with the `anonymous,review` class options (the starter `main.tex` already sets them); remove author names, affiliations, and identifying acknowledgements.
双盲评审：使用 `anonymous,review` 文档类选项（起始模板已设置），删除作者、单位与致谢中的身份信息。

## Bibliography / 参考文献样式

`ACM-Reference-Format` (BibTeX). Ships with the `acmart` package in TeX Live / MiKTeX.
使用 `ACM-Reference-Format`（BibTeX），随 TeX Live / MiKTeX 的 `acmart` 宏包提供。

## Toolchain / 编译工具链

pdflatex (via latexmk). Run the official ACM toolchain (TAPS) before camera-ready submission.
使用 pdflatex（latexmk 驱动）；终稿提交前请以 ACM 官方工具链（TAPS）完整编译一次。
