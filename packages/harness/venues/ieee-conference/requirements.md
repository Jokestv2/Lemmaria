# IEEE conference (IEEEtran) — submission requirements / 投稿要求

## Page limit / 页数限制

Varies per conference (commonly 6–8 pages, extra pages often paid) — **check your conference's CFP**; no limit is pinned in the manifest for this reason.
各会议不同（常见 6–8 页，超页常需付费）——以会议 CFP 为准；因此清单未固定页数。

## Anonymity / 匿名要求

Most IEEE conferences are single-blind (author names visible). If yours is double-blind, anonymize the author block manually.
多数 IEEE 会议为单盲（可署名）；如为双盲，请自行匿名化作者信息。

## Bibliography / 参考文献样式

`IEEEtran` (BibTeX). Ships with the `IEEEtran` package in TeX Live / MiKTeX.
使用 `IEEEtran`（BibTeX），随 TeX Live / MiKTeX 提供。

## Toolchain / 编译工具链

pdflatex (via latexmk). Verify with the official IEEE PDF eXpress before submission.
使用 pdflatex（latexmk 驱动）；提交前请用 IEEE PDF eXpress 校验。
