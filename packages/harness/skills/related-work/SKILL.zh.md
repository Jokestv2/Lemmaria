# 相关工作

1. **按本文的贡献维度分组**，而不是按时间顺序，也不是按会议期刊。本节的任务是给本文定位，
   因此每一组的结尾都应写出它留下了什么未解——那正是下一节声称要解决的问题。
2. **引文能支撑的是"某工作做了什么"。** 元数据与摘要足以支撑"X 提出了 Y"，但不足以支撑
   "X 无法处理 Z""X 很慢""X 后来被证明是错的"——这些需要读过该论文自己的结果。
3. **绝不断言你没有测量过的比较。** "与我们不同，他们无法……"是一句披着引文外衣的实验结论。
4. **检索源没有应答，不等于该领域没有工作。** 若检索被限流或某个源失败了，那是检索的缺口，
   不是该方向为空的证据。要写明究竟是哪一种。
5. **只有当手上的元数据确实能锁定该工作时才添加参考文献**——标题、作者、年份都对得上。把
   一个相近但不同的检索结果当作原文引用，就是一条伪造的参考文献，也是本节最容易犯的错。
6. **优先使用正式发表版本**，并保持会议/期刊名称与全文参考文献的写法一致。
7. **每一篇被点名的工作都要配得上它占的那一句话。** 只堆引文而不给出论断，读者一无所获，
   还占用了本该留给贡献的篇幅。
