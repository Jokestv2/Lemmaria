# Related work

1. **Group by the axis you are contributing on**, not chronologically and not by
   venue. The section's job is to place this paper, so each group should end with what
   it leaves open — which is what the next section claims to close.
2. **A citation supports a claim about what a work DOES.** Metadata and an abstract
   support "X proposes Y". They do not support "X does not handle Z", "X is slow", or
   "X was later shown wrong" — those need the paper's own results, read.
3. **Never assert a comparison you have not measured.** "Unlike ours, theirs cannot…"
   is an experimental claim wearing a citation's clothes.
4. **A source that did not answer is not an absence of work.** If a search was rate
   limited or a source failed, that is a gap in the search, not evidence that the area
   is empty. Say which it is.
5. **Add a reference only when the metadata you have actually identifies the work** —
   matching title, authors and year. A near-miss search hit cited as the real thing is
   a fabricated reference, and it is the failure mode this section is most prone to.
6. **Prefer the version of record** where you have it, and keep the venue string
   consistent with the rest of the bibliography.
7. **Every work you name should earn its sentence.** A list of citations with no claim
   attached tells a reader nothing and costs the page budget the contribution needs.
