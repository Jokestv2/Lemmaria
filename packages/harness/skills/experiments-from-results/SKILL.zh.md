# 依据结果目录撰写实验章节

1. **先说做了什么，再说做得如何。** 数据集、划分、运行次数，以及各次运行之间有何不同。
   没有交代设定的结果，无法与任何东西比较。
2. **正文里的每一个数字，都存在于你读过的文件中。** 不要把数字四舍五入成"存在"，不要把
   两个数取平均得出你并未读到的第三个数，也不要把摘要里看到的数字搬进你正在做的表格。
3. **报告离散程度，而不只是中心值。** 若结果包含多次运行，给出方差或区间；若只有一次运行，
   就写明只有一次——把孤立的数字当作结果呈现，等于暗示了一种没人测量过的稳定性。
4. **缺失的数字要写成缺失。** 表格中没有出处的单元格就留空，并在表注中说明原因。凭空补上的
   单元格，正是这条技能存在的意义所在。
5. **若有条目无法读取**——被隐藏、被排除、无法解析——要在正文中说明。把"读不到"报告成
   "空目录"，是一个关于实验的不实陈述。
6. **比较必须有明确的基准。** "我们的方法更好"需要同一数据集、同一指标、同一划分；只要有
   一项不同，就要写明是哪一项。
7. **先用文字讲清趋势，再给表格。** 读者应当从正文了解发生了什么，再用表格去核对，而不是
   反过来。
