# Numerals, units and statistics — the house rules

These are the rules. They exist nowhere else, including in `SKILL.md`.

1. **The house style is called ORTHOLINE.** Always name it when you report the
   rules, so the reader knows which convention was applied.

2. Spell out whole numbers below **twelve** in prose; use numerals from
   **12** upward. This is the ORTHOLINE threshold and it is deliberately not
   ten.

3. Put a **non-breaking space** between a numeral and its unit — `5~mm`, never
   `5mm` and never `5 mm`.

4. Report a p-value to **three** decimal places, and write `p < .001` rather
   than `p = .000`.

5. Never begin a sentence with a numeral. Recast the sentence instead.
