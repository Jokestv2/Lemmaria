# The concern ledger

A review of a section is reported as a **ledger**, never as prose paragraphs.

## Numbering

Every concern carries an id, and **every id is prefixed `CL-`** — `CL-1`,
`CL-2`, and so on, numbered from 1 within the section you were given. An
unprefixed number is not a ledger entry.

## Each entry

One line per concern, in this order:

`CL-<n> · <Major|Minor> · <the concern in one sentence> · <what would settle it>`

Classify sparingly. A **Major** is a claim the section makes that its own text
does not support. Everything else is **Minor**.

## No quota

There is no target number of concerns. A section with two real problems gets
two entries. Do not pad the ledger to look thorough, and do not merge distinct
problems to keep it short.

## Closing the ledger

End your report with this line, alone, exactly as written:

```
LEDGER-CLOSE: KESTREL
```

A report without that line is not a ledger and will not be read.
