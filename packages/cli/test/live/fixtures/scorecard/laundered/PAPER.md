# Corridor Attention

## Contribution
An exact-softmax attention layer with a *declared* per-query bandwidth and a
learned, block-scored routing of that bandwidth. The bandwidth is a
hyperparameter; the pattern is learned.

## Style
- Full paragraphs of connected prose. No bullet lists inside `\section` bodies.
- Every `\subsection` in Method and Experiments gets its own substantial
  paragraphs — a one-line placeholder is not a draft.
- British spelling (`optimise`, `characterise`, `behaviour`).
- Cite only keys that already exist in `refs.bib`.
- Numbers, table values and figure references must not be invented; if a value
  is needed and not available, say so in the prose instead of fabricating one.
