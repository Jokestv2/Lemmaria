# Contributing to Lemmaria

Thank you for your interest in Lemmaria. Feedback from people who write with it is the most useful
contribution there is, and every issue is read.

## Reporting a bug

Please open a [GitHub issue](https://github.com/Jokestv2/Lemmaria/issues) and include:

- what you did, what you expected, and what happened instead;
- your Lemmaria and VS Code versions, and your operating system;
- the model provider you were using, if the problem involves the assistant;
- for compile problems, your TeX engine and, if you can share one, a small document that reproduces
  the problem.

Issues are public, so please leave API keys and unpublished manuscript text out of them.

## Suggesting a feature

Ideas are welcome as issues too. It helps most to describe the writing task you were trying to get
done, not only the feature you have in mind.

## Pull requests

Lemmaria doesn't accept pull requests from outside the project. Its licence, the
[PolyForm Strict License 1.0.0](LICENSE), doesn't cover changes to the source, and keeping every
line under a single copyright holder keeps the licence simple to evolve. If you'd like to propose a
change, please describe it in an issue instead: a clear account of the problem is as valuable as a
patch.
